LOG 

This is the machine's diary. No camera is running here: the machine imagines it is watching five Greek cities and writes down every pollution box it would draw. Each line is one invented detection. What is real is the air: the pollutant chosen, the measured value and the writing speed all come from the live data. The dirtier the air, the faster it writes.
